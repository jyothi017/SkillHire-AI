# SkillHire AI — Interview Preparation Platform

SkillHire AI is an interview preparation platform designed for college placement students. It helps students practise role-based interview questions, explore skill coverage, and evaluate their answers using rubrics.

## Website Preview

![SkillHire AI Dashboard](skillhire-dashboard.png)

## Features

- Practice interviews for different job roles.
- Generate questions using a built-in question bank and templates.
- Select basic, intermediate, and advanced difficulty levels.
- Review skill coverage and evaluation rubrics.
- Organize interview practice sessions.
- Use a Node.js, Express, and PostgreSQL backend for supported API operations.

## Tech Stack

**Frontend:** HTML, CSS, JavaScript

**Backend:** Node.js, Express.js

**Database:** PostgreSQL

## Project Structure

- `SkillHire-AI-frontend/` — Website interface and frontend logic.
- `SkillHire-AI-backend/` — REST API, database schema, and backend configuration.
- `README.md` — Overall project documentation.

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/jyothi017/SkillHire-AI.git
   ```

2. Open `SkillHire-AI-frontend/` in VS Code and run `index.html` using Live Server.
3. To run the backend, follow the setup instructions in `SkillHire-AI-backend/README.md`.
4. Configure PostgreSQL and your local `.env` file using the backend's example configuration.

## Limitations

- The current frontend uses a built-in question bank and templates; it does not use a live AI model.
- Frontend-to-backend integration should be verified for each feature.
- Review generated questions and evaluation rubrics before using them in real hiring decisions.
